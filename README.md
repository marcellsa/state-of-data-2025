# 📊 Análise do Mercado de Dados para Profissionais 40+

Este projeto faz parte do **Desafio State of Data 2024-2025**, proposto pela comunidade [Data Hackers](https://www.datahackers.com.br/) com base nos dados da pesquisa anual **State of Data Brazil**.

O estudo investiga se profissionais com **40 anos ou mais** enfrentam barreiras no mercado de dados, abordando temas como progressão de carreira, cargos ocupados e domínio de ferramentas modernas.

---

## Contexto

O mercado de dados cresce em ritmo acelerado, impulsionado pela transformação digital. No entanto, há sinais de que esse crescimento pode não estar igualmente acessível a todas as faixas etárias. Profissionais 40+ muitas vezes enfrentam o estigma da defasagem técnica e a dificuldade de transição para áreas altamente dinâmicas como dados, TI e marketing digital.

Este estudo busca entender melhor essa realidade usando dados reais de mais de 5 mil profissionais da área de dados no Brasil.

---

## Objetivos

1. Verificar se profissionais 40+ enfrentam barreiras para crescer na carreira.
2. Avaliar se estão mais concentrados em cargos técnicos ou de gestão.
3. Investigar o domínio de ferramentas modernas por parte do grupo 40+.

---

## Hipóteses Investigadas

| Hipótese                                                                 | Resultado       |
|--------------------------------------------------------------------------|-----------------|
| H1. Profissionais 40+ enfrentam mais dificuldade para progredir na carreira. | ✅ Parcialmente confirmada |
| H2. Profissionais 40+ estão mais concentrados em áreas menos técnicas ou mais voltadas à gestão. | ✅ Confirmada |
| H3. Profissionais 40+ apresentam menor domínio ou uso de ferramentas modernas. | ❌ Refutada     |

---

## Principais Conclusões

- Profissionais 40+ representam **apenas 16% da amostra**, indicando possível sub-representação no mercado.
- A maioria dos 40+ ainda ocupa **cargos técnicos**, mesmo com maior experiência.
- O grupo 40+ **usa ferramentas modernas de forma equivalente ou superior** ao grupo mais jovem, mostrando forte capacidade de adaptação técnica.
